
Actions in this directory are focused on **documentation** — building, transforming, and publishing project documentation sites.

Actions here should be concerned with one or more of the following:

- Building static documentation sites from source files
- Deploying documentation to hosting platforms or GitHub Pages
- Validating documentation structure, links, or content
- Transforming or pre-processing documentation assets before publishing
- Keeping documentation in sync with project artifacts such as API specs or changelogs

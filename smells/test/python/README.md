Actions in this directory are focused on **Python testing** — running Python test frameworks, measuring coverage, and reporting results.

Actions here should be concerned with one or more of the following:

- Setting up Python environments and installing project dependencies
- Running Python test frameworks such as pytest, unittest, or tox
- Generating coverage reports in standard formats (lcov, xml, html)
- Posting coverage summaries and PR comments
- Supporting projects structured as installable Python packages with `[dev]` extras

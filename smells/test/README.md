Actions in this directory are focused on **automated testing** — running test suites, measuring coverage, and surfacing results throughout the CI lifecycle.

Actions here should be concerned with one or more of the following:

- Running unit, integration, or end-to-end test suites
- Generating code coverage reports in standard formats (lcov, xml, html)
- Publishing coverage summaries to the GitHub Actions step summary
- Posting or updating coverage comments on pull requests
- Failing CI when coverage thresholds are not met

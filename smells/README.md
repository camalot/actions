
Actions in this directory are focused on **code quality** — detecting code smells, enforcing style, and surfacing issues before they reach production.

Actions here should be concerned with one or more of the following:

- Linting source code across one or more languages or toolchains
- Enforcing coding standards and style conventions
- Detecting anti-patterns, complexity issues, or security smells
- Reporting quality violations as annotations, comments, or step summaries
- Running static analysis tools as part of a pull request or CI gate


Actions in this directory are focused on **semantic versioning** — determining, managing, and publishing version numbers throughout the software release lifecycle.

Actions here should be concerned with one or more of the following:

- Calculating the next semantic version from commit history
- Reading, writing, or synchronizing version identifiers across files and artifacts
- Creating, moving, or validating version tags in a git repository
- Producing changelogs or release notes derived from versioned commits
- Publishing or managing GitHub Releases tied to a version
